RaigonOS

A gallery an artist can run without touching code.

Live site ↗ Code ↗
Role
Design & full-stack development
Stack
Django, PostgreSQL, Cloudinary, Render
Type
Web app · Personal project
Status
Live · 2026

Challenge

Artists need a place to publish and organise their work, but most tools either need code or flatten artwork into a generic grid. Only the owner should be able to change content, and uploads had to survive a host that wipes its filesystem on every deploy.

Approach

Two related models, Collection and Artwork, with full CRUD scoped to the logged-in owner. A private dashboard with search, grid and list views, archive status and a light/dark theme, plus a read-only public gallery that feels like walking through an exhibition.

Outcome

A live, deployed product with real collections in it. Setup is environment-driven: SQLite locally, PostgreSQL on Render, images on Cloudinary, so nothing is lost between deploys.

Cublok

Colour as a material decision, not a digital effect.

Live site ↗ Code ↗
Role
Concept, design & front-end development
Stack
HTML, CSS, vanilla JavaScript, Canvas 2D
Type
Web app · Developed in Zürich
Status
Live · 2026

Challenge

Artists who build images from solid units (tiles, mosaics, cross-stitch, physical pixels) have no tool that thinks like them. Image editors work in pixels for screens; vector tools work in curves for print. Neither works in centimetres.

Approach

A browser tool where every cell is one physical centimetre and gets one solid mark: square, circle, triangle or cross. Images convert to a grid with k-means colour extraction, all client-side, with no backend, framework or build step.

Outcome

A printable, colour-coded build sheet turns each design into magnetic cubes on a wall. The piece can be taken apart and rebuilt as a new composition, so the same wall can change with the season.

Arca Vault

Imagine knowing the exact day you’ll hit your first million.

Role
UX/UI design, research to hi-fi prototype
Tools
Figma
Type
Mobile app · Fintech
Status
Concept

Challenge

People put off financial decisions. Banking apps show balances, not direction, so setting a goal and sticking to it feels hard and unclear.

Approach

One app that combines banking data, behavioural insights and credit health. A compound calculator turns savings into a date, and a portfolio view shows progress toward it.

Outcome

  • 91% felt more in control of their finances
  • 3× faster decisions vs. banking apps
  • 64% hit a savings milestone within 30 days

Dronzza

Hot pizza, dropped from the sky before the box even cools.

Role
UX/UI design
Tools
Figma
Type
Mobile app · Food delivery
Status
Concept

Challenge

People don’t yet trust unmanned delivery, there is no UX pattern for a drone drop-off, and weather or no-fly zones can block an order at any time.

Approach

An order flow built around drone logistics: live tracking so you always see where your food is, and smart drop-zone selection so you know exactly where it lands.

Outcome

A complete flow from wireframes to high-fidelity screens, designed for delivery in minutes, not motorcycles.
